How Wi‑Fi mode stays private

Browsers cannot open raw network sockets, so Annex installs a tiny bridge on the phone (/data/local/tmp, runs as the ADB shell user, no app install). The page and bridge share a random 256‑bit key that only ever travelled over the USB cable. Every byte between them is encrypted with AES‑256‑GCM using fresh per-connection keys (HKDF), so other devices on the network can't read or inject anything. ADB's own RSA authorisation still applies on top.

Wi‑Fi mode switches ADB to network mode (port 5555) until the phone reboots. Turn it off here to return to USB-only.

Troubleshooting

        
“Interface in use” / cannot claim device
Only one program can talk ADB over USB at a time. Close Android Studio / scrcpy or run adb kill-server.

        
No phone in the USB picker
Check that USB debugging is on, the cable carries data and the phone is unlocked. On Windows the ADB interface needs a WinUSB-compatible driver (Google USB driver or the OEM one). On Linux, add a udev rule giving your user access to the phone (e.g. SUBSYSTEM=="usb", ATTR{idVendor}=="18d1", MODE="0666").

        
Video works but taps/keys do nothing
Xiaomi / Redmi / POCO: also enable USB debugging (Security settings). Some phones need Disable permission monitoring (ColorOS / realme) in developer options.

        
Samsung: USB debugging greyed out
Turn off Auto Blocker (Settings ▸ Security and privacy).

        
Wi‑Fi mode won’t connect
Phone and PC must be on the same network, and the network must allow device-to-device traffic (guest Wi‑Fi often doesn’t). After a phone reboot, connect via USB once and enable Wi‑Fi mode again. If the IP changed, edit it on the start screen. Chrome may ask to allow access to devices on your local network.

        
Laggy or blurry stream
Lower the resolution limit or raise the bitrate in Settings. H.265 halves bandwidth if your GPU decodes it. Over Wi‑Fi, 5 GHz makes a big difference.

        
Install as an app

        
Browsers can only install pages served over http(s), not files opened from disk. Unzip annex-pwa.zip and run start-annex once: it serves Annex on http://localhost:27180 and opens it — click Install app in the top bar. Afterwards the installed app starts without the server and works fully offline.

        
About

        
Annex runs entirely in this page. Its content security policy forbids every network request except WebSocket connections to your phone. Mirroring uses the open-source scrcpy 3.3 server (Apache-2.0, Genymobile) pushed to /data/local/tmp; the ADB stack is Tango (MIT). Nothing is installed on the phone and nothing is uploaded anywhere.
